# Sip Happens Café

Застосунок для оцінювання обслуговування в кафе. Після першого голосу показує
кількість оцінок, загальну кількість голосів і відсоток позитивних. Кнопка
Reset скидає статистику.

## Запуск

Потрібні Node.js 24+ та npm.

```sh
npm ci
npm run dev
```

Для перевірки запусти `npm run lint` і `npm run build`.

Адаптовано з [02-react-cafe Софії Дорош](https://github.com/sofiiadorosh/02-react-cafe).
